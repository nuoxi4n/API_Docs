# m3u8视频播放器

> m3u8播放器支持播放网络上所有主流音视频格式文件。例如：m3u8、hls、dash、flv、mp4等

## 接口地址

```http-vue
https://api.nxvav.cn/api/{{$frontmatter.api}}/
```

## 请求参数

| 参数名 | 类型 | 必填 | 说明 |
| - | - | - | - |
| url | string | 是 | 视频直链，支持 hls、dash、flv、webtorrent、mp4 等格式 |
| type | string | 否 | 视频类型，可选值`auto`，`hls`，`flv`，`dash`，`normal`。不填默认`auto` |
| cover | string | 否 | 视频封面图片直链链接 |
| live | boolean | 否  | 直播模式，可选值`true`，`false`。不填默认`false` |
| autoplay | boolean | 否 | 自动播放，可选值`true`，`false`。不填默认`false` |
| hideplay | boolean | 否 | 隐藏控件，可选值`true`，`false`。不填默认`false` |
| loop | boolean | 否 | 循环播放，可选值`true`，`false`。不填默认`false` |
| lang | string | 否 | 播放器语言，可选值`en`，`zh-cn`，`zh-tw`，`ko-kr`，`de`，`ja`，`ru`。不填默认`zh-cn` |

## 返回响应

| 字段名 | 类型 | 说明 |
| - | - | - |
| HTML | text/html | 网页播放器 |
