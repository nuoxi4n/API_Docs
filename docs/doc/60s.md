## 请求参数

| 参数名   | 类型   | 必填 | 说明                                                    |
| -------- | ------ | ---- | ------------------------------------------------------- |
| date     | string | 否   | 获取时间，默认今天，格式： 2025-03-01                   |
| encoding | string | 否   | 编码方式，支持 `text` `json` `image` `image-proxy` 四种 |

## 返回响应

| 字段名         | 类型          | 说明            |
| -------------- | ------------- | --------------- |
| code           | integer       | 状态码          |
| message        | string        | 返回信息        |
| data           | object        | 返回数据        |
| - date         | string        | 60s 日期        |
| - news         | array[string] | 60s 新闻        |
| - image        | string        | 完整的 60s 图片 |
| - tip          | string        | 每日一句        |
| - cover        | string        | 封面头图        |
| audio          | object        | 音频信息        |
| - music        | string        | 音频链接        |
| - news         | string        | 60s 新闻        |
| link           | string        | 新闻链接        |
| created        | string        | 发布时间        |
| created_at     | integer       | 发布时间戳      |
| updated        | string        | 更新时间        |
| updated_at     | integer       | 更新时间戳      |
| day_of_week    | string        | 星期几          |
| lunar_date     | string        | 农历日期        |
| api_updated    | string        | 接口更新时间    |
| api_updated_at | integer       | 接口更新时间戳  |
